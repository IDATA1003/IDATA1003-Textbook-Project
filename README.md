# IDATA1003-Textbook-Project
Java-projects from the textbook "Objects First with Java" 7th edition

The original projects as provided with the textbook, can be found under the folder /bluej/projects. The projects can be found on the BlueJ web-page at [https://www.bluej.org/objects-first/](https://www.bluej.org/objects-first/)

All projects have also been implemented as **Maven projects** to enable the projects to be opened in any professional IDE like VSCode and IntelliJ IDEA etc. These can be found in the folder /maven/projects.
